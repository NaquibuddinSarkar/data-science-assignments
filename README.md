# Data Science Coursework and Assignments

A curated collection of coursework and practical assignments completed during data science training. The repository is organised by topic so that notebooks and supporting datasets can be explored independently.

## Topics

1. Python foundations
2. Pandas and exploratory data analysis
3. Data visualisation
4. Statistical analysis
5. Machine learning
6. Time-series forecasting
7. Model deployment

## Forecasting methods represented in the coursework

The time-series section includes work involving Prophet, ARIMA/SARIMA, Holt-Winters, and related forecasting workflows. The notebooks should be read as learning exercises and coursework, not as claims of production-ready models.

## Repository notes

- Notebooks may require the accompanying datasets and dependencies.
- Start with the notebook and its local README, where available.
- Install dependencies with `pip install -r requirements.txt`.
- Some notebooks may need minor environment-specific adjustments.
- Results have not all been independently re-executed in a clean environment.
- Dataset redistribution rights should be checked before reusing or redistributing any data.

## Academic integrity and attribution

These materials are presented as coursework and practical exercises. They should not be represented as independent commercial projects or production deployments. Where an exercise builds on a course-provided dataset, template, or instruction, retain the original attribution and context.
